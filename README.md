# WoodForma Demo

Готовый демонстрационный сайт для мебельной мастерской. Проект предназначен для портфолио и показа потенциальным клиентам.

## Стек

- Next.js 15
- React 19
- TypeScript
- Чистый CSS

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

## Сборка

```bash
npm run build
npm run start
```

## Развёртывание на Vercel

1. Импортируйте репозиторий в Vercel.
2. Framework Preset: Next.js.
3. Остальные настройки можно оставить стандартными.
4. Нажмите Deploy.

## Быстрая адаптация под клиента

Основной контент находится в `app/page.tsx`:

- название и телефон;
- заголовки и преимущества;
- массив `projects` с работами;
- этапы производства;
- ссылки Telegram и email.

Стили находятся в `app/globals.css`. Основные цвета вынесены в CSS-переменные в начале файла.

## Форма заявки

Сейчас форма работает в демонстрационном режиме и показывает экран успешной отправки. Для реального клиента её можно подключить к Telegram-боту, CRM, email или серверному API.

## Важно

Название WoodForma, контакты, цены, отзывы и описание компании являются демонстрационными. Перед коммерческим запуском их нужно заменить данными клиента. Фотографии подключены через Unsplash и используются только для демонстрации дизайна.
